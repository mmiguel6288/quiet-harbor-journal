0 · Time Desk (read this first)

In one line: Clocks lied that night because 1 AM happened twice. Convert everything to UTC to see the true order.

What happened
On the night of Sat 11/1 → Sun 11/2/2025, daylight saving time ended.
At 2:00 AM PDT the clocks went back to 1:00 AM PST.
So every time from 1:00 to 1:59 AM happened twice: first the first 1 o'clock (PDT), then the second 1 o'clock (PST).

The fix: use UTC, one clock that never jumps.
PDT = UTC−7: add 7 hours to get UTC.
PST = UTC−8: add 8 hours to get UTC.
A local time like “1:20 AM” is a puzzle until you know which 1 o'clock it was.

Made-up example: a phone showing 1:30 AM after the clocks went back = 09:30 UTC. The same phone showing 1:30 AM before = 08:30 UTC.		 Quick table

Three kinds of clock. For each device or record you meet, write it below and pick its kind:

  • A · UTC: the record is already in UTC. Use its time as it is.
  • B · Auto local: local time that sets itself (phones, network-synced devices). Before the clocks went back it shows PDT: add 7 h. After, it shows PST: add 8 h.
  • C · Hand-set: local time set by hand, or never changed. After the clocks went back it may read an hour off. Work out which offset it was really on, then convert.

Counters don't lie. Numbers that only go up (sequence numbers, transaction numbers) show the true order, whatever any clock says.
